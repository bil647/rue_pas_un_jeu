# السكريبت العربي — « الشارع ليس لعبة »

| الوقت | الشخصية | النص |
|---|---|---|
| 0–5 ث | راوٍ | في شوارعنا، يرى بعض الأطفال أشياء ليست لهم. |
| 5–12 ث | آدم | تعال! انظر، أنا أقلده! |
| 5–12 ث | ليلى | توقف يا آدم! هذه ليست لعبة. |
| 12–19 ث | ليلى | أرأيت ماذا يفعل؟ هذا ليس للأطفال. |
| 12–19 ث | آدم | لماذا يبيع هذا أمام المدرسة؟ |
| 19–27 ث | راوٍ | عندما يبيع شخص بالغ مخدرات قرب الأطفال، قد يظنون أن هذا عادي. لكنه ليس عادياً. |
| 27–36 ث | الأم | المخدرات تدمر الصحة والمستقبل. بيعها أمام الأطفال أمر خطير جداً. |
| 27–36 ث | آدم | إذن ماذا نفعل؟ |
| 36–45 ث | ليلى | لا نلمس. لا نقلد. نتحدث إلى شخص بالغ. |
| 36–45 ث | الأم | ونبلغ. حماية الأطفال مسؤولية الجميع. |
| 45–54 ث | راوٍ | الطفل يجب أن يلعب ويتعلم ويحلم. لا أن يقلد الشارع. |
| 54–60 ث | صوت | لنحمِ الأطفال. أبلغوا عن أي تجارة مخدرات. |
```
